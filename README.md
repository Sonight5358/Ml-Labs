## Лабораторные работы

### ЛР1 - Введение в Python

**Ноутбук:** [`src/01_lab_python_intro.ipynb`](src/01_lab_python_intro.ipynb)

Лаба 1, задача была в том, чтобы вспомнить основы Python: заполнить ячейки ноутбука так, чтобы прошли все `assert`ы. Создал переменные базовых типов (`int`, `float`, `str`, `bool`, `list`, `tuple`, `set`, `dict`), написал функции на условия, циклы, работу со строками, списками, множествами и словарями (калькулятор, подсчёт вхождений без `collections.Counter`, перевод минут во время на часах, поиск максимума с индексом и т.д.), реализовал две математические функции через модуль `math`, а также классы `Vehicle`, `Truck` (наследник `Vehicle`) и `MyList`. В итоге все проверки в ноутбуке проходят, ошибка остаётся только в демонстрационной ячейке `assert a > 6`, как и предполагается заданием.
